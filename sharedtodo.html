みてみてTODO プライバシーポリシー

あぷりだすお（apuridasuo、以下「運営者」）は、提供するアプリにおける利用者情報の取り扱いを、以下のとおり定めます。 「みてみて TODO」（英語名：Shared ToDo、以下「本アプリ」）のデータ保存・共有・通知については、本ページの該当項目が適用されます。

最終更新日：2026年9月25日

1. 広告配信について

運営者が提供するアプリのうち、広告を表示するアプリでは、Google の AdMob を利用します。 広告 SDK は、IP アドレス、端末・広告に関する識別子、広告やアプリの操作情報、診断情報などを取得・送信する場合があります。 これらは広告配信、効果測定、不正利用防止などに利用されます。

本アプリでは Google User Messaging Platform（UMP）を利用して広告に関する同意情報を確認し、必要な場合に同意画面やプライバシー設定の入口を表示します。 表示される場合は、その画面から選択を変更できます。

Google による情報の取り扱いは、以下をご確認ください。
- Google プライバシーポリシー
- Google 広告に関するポリシーと仕組み

2. みてみて TODO で取り扱う情報と利用目的

本アプリでは、TODO の保存、端末間の同期、リストの共有、更新通知、不正利用防止のため、次の情報を取り扱います。

  • 利用者を識別する情報： Firebase Authentication が発行するユーザー ID。
  • 入力・編集した情報： TODO 本文、リスト名、完了状態、表示順、削除状態、作成・更新時刻、更新した利用者を識別する情報。
  • 共有に関する情報： リストへの参加状況、参加時刻、共有用の合言葉とその照合情報、参加操作の回数等。
  • 通知に関する情報： 通知先端末を識別する Firebase Installation ID、端末の OS 種別、通知の許可・設定状態、通知処理の履歴。
  • 動作・通信に関する情報： 同期に必要な情報、エラーや処理結果のログ等。

運営者は、問い合わせを受けた場合、利用者が連絡時に提供した連絡先や内容を、問い合わせへの対応に利用します。

3. データの保存と共有

本アプリは Google の Firebase Authentication、Cloud Firestore、Cloud Functions for Firebase、Firebase Cloud Messaging 等を利用し、前項の情報をサーバーへ送信・保存・処理します。 また、オフライン利用や設定の保持のため、一部の情報を端末内に保存します。

同じ共有リストに参加した利用者は、そのリストの TODO 本文、リスト名、完了状態等を閲覧・編集できます。 合言葉を知っている人は、参加が許可されている間、そのリストへ参加できるため、合言葉の共有先にご注意ください。

本アプリは、TODO 本文やリスト名を広告のターゲティング情報として AdMob へ渡す処理を行いません。 広告 SDK による情報の取得・送信は「1. 広告配信について」のとおりです。

外部サービスによる情報の処理・保存は、各サービスの利用条件、設定およびプライバシーポリシーに従います。

- Firebase のプライバシーとセキュリティ
- Google プライバシーポリシー

4. Push 通知について

通知を有効にした場合、共有リストの更新を知らせるために、Firebase Cloud Messaging および OS の通知配信サービスを利用します。

更新通知には、リスト名、変更の種類や件数などが表示されます。TODO 本文そのものは更新通知に含めません。 端末の設定によっては、通知がロック画面にも表示されます。

通知は、本アプリの通知設定、リストごとの通知設定、または端末の OS 設定から停止できます。 通知の停止は、共有データや過去の登録情報の完全削除を意味しません。

5. 保存期間と削除について

共有リストの情報は、リストの利用・同期・共有を提供する間、サーバーに保存します。 アプリで TODO を削除した場合、通常の一覧からは表示されなくなりますが、取り消しや同期に使う削除済みデータがサーバーに残る場合があります。

リストから退出すると、その利用者の参加情報とタブ情報を削除します。 他の参加者がいるリストとその TODO は引き続き保存されます。 全員が退出したリストは削除状態となり、30 日を経過したものがサーバーの定期削除処理の対象になります。

アプリのアンインストールや、端末からタブを削除する操作だけでは、サーバー上のすべてのデータが削除されるわけではありません。 利用者に関するデータの確認・削除を希望する場合は、下記の問い合わせ先へご連絡ください。

お問い合わせ：support@sharedtodo.app

6. 情報の保護

本アプリと利用するサービスでは、通信の暗号化やアクセス権限の制御を利用し、情報の保護を図ります。 共有リストの内容は他の参加者にも表示されるため、共有したくない情報の入力にはご注意ください。
